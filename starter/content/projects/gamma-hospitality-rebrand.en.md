## The challenge

Gamma Hotels had four hotels, each with its own image, and a website that did not connect them. Guests did not realise they belong to the same family.

## The approach

We defined a shared identity with room for each hotel's character. The website follows it, and the same elements were used in print and signage.

## The result

A website with a shared structure and a large gallery for each hotel, easy for the group's team to update.
