phpFlat Admin — Templates

Static HTML + Tailwind interface foundation · ready to split into PHP view partials

Preview uses the Tailwind Play CDN. In phpFlat, replace the single CDN <script> in each file with your locally compiled /assets/css/app.css. The markup is pure Tailwind utility classes — nothing else changes. Interactions live in /assets/js/admin.js (vanilla, data-attribute driven).
